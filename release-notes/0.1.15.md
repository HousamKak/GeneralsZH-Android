## en
# Online matches that stay in sync
- Phones on different game speeds (30 and 60 Hz) can no longer start a match together; that is what caused the mismatch at the start
- Joining a game that is set up differently now says what to change: game speed, game data, or cross-play for PC games
- Game speed in ZH COMMANDER now reads 30 HZ (WITH PHONES) and 60 HZ (WITH PC)

## ar
# مباريات أونلاين تبقى متزامنة
- لم يعد بإمكان هواتف بسرعات لعب مختلفة (30 و60 هرتز) بدء مباراة معًا؛ هذا ما كان يسبب عدم التطابق عند البداية
- الانضمام إلى لعبة بإعدادات مختلفة يوضّح الآن ما يجب تغييره: سرعة اللعب أو بيانات اللعبة أو اللعب مع الكمبيوتر
- سرعة اللعب في ZH COMMANDER أصبحت 30 هرتز (مع الهواتف) و60 هرتز (مع الكمبيوتر)
