## en
# Settings, support and updates inside the game
- The app version is shown on the main menu and in Options
- SUPPORT on the main menu sends a report straight to the developer and gives you a reference code
- Options has a ZH COMMANDER screen: game speed, renderer, upscaling, interface and text size
- New versions and new game data are offered on the main menu, in the game's own style
- Anonymous usage and crash data help fix bugs faster; you can turn it off in ZH COMMANDER

## ar
# الإعدادات والدعم والتحديثات داخل اللعبة
- يظهر رقم إصدار التطبيق في القائمة الرئيسية وفي الخيارات
- زر الدعم في القائمة الرئيسية يرسل تقريرًا مباشرة إلى المطوّر ويعطيك رمزًا مرجعيًا
- في الخيارات شاشة ZH COMMANDER: سرعة اللعبة، محرّك الرسوميات، تحسين الدقة، وحجم الواجهة والنص
- تُعرض الإصدارات الجديدة وبيانات اللعبة الجديدة في القائمة الرئيسية، بأسلوب اللعبة نفسه
- بيانات الاستخدام والأعطال المجهولة الهوية تساعد على إصلاح المشاكل أسرع، ويمكنك إيقافها من ZH COMMANDER
